# Specifications

Interface and format specifications that code is written against. Expected first entries:

- `lean-facts.md`: the JSON the Lean helper emits (SPIKE-05)
- `statement-hash.md`: what a lock hash covers (SPIKE-03)
- the event schema (ADR-0016), once SPIKE-07 reports what providers expose

A specification states its version and is changed only together with the code and tests that
implement it.
